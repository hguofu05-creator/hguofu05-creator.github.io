## 从零搭建个人摄影作品集网站（Astro 5 + Tailwind + GitHub Pages）

- 技术栈：Astro 5 + Tailwind CSS v3（`@astrojs/tailwind` 集成）+ TypeScript。纯静态，无后端/DB/CMS。
- 配色：影视飓风风格，定义在 `tailwind.config.mjs`（oklch: bg 0.15/0/0, bg-2 0.22, fg 0.95, muted 0.65 0.01 260, accent 0.75 0.15 240）。
- 5 个页面：`src/pages/` 下 index(首页Hero+瀑布流) / gallery(筛选+网格) / photo/[slug](详情+灯箱+上下张) / about / contact / 404。
- 照片源：桌面 `C:\Users\ocean\Desktop\作品集`（84 张手机 JPG，含 MVIMG 动态照片、mmexport 微信导出）。
- 图片管线：`scripts/process-images.mjs` 用 sharp 生成 400/800/1600 WebP 到 `public/images/photos/`，exifr 抽 EXIF，写 `src/data/photos.json`。
  - 手机 EXIF 缺 Make/Model/FNumber/ExposureTime/FocalLength；日期从文件名解析（IMG_YYYYMMDD / mmexport<epoch13>），ISO 用 ISOSpeed，光圈用 MaxApertureValue(APEX)。
  - 已实际运行：生成 252 个 WebP（23MB，原图 313MB），photos.json 84 条。
- `npm run build` 通过（89 页），`npm run preview` 各路由 200。
- 部署：`.github/workflows/deploy.yml` 走 GitHub Actions；推荐仓库命名 `<用户名>.github.io`（免 base 配置）。
- 注意事项：用户是编程新手，下一步需手动编辑 `src/data/photos.json` 补 title/category/story/location，并在 `src/consts.ts` 改名字/邮箱/社交链接；关于页头像放 `public/images/about.webp`。
